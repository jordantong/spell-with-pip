SPELL WITH PIP — putting it on the iPad
=======================================

This "docs" folder is the whole app. It needs to live on a web address once,
then the iPad keeps its own copy and works offline.

1. PUT IT ONLINE (free, no command line needed)
   - On github.com, create a public repository named spell-with-pip.
   - Add file > Upload files, drag the "docs" folder in, Commit changes.
   - Settings > Pages > Source: Deploy from a branch; Branch: main, /docs.
   - Your app is then at https://jordantong.github.io/spell-with-pip/

2. INSTALL ON THE iPad
   - Open https://jordantong.github.io/spell-with-pip/ in Safari on her iPad.
   - Tap the Share button, then "Add to Home Screen", then "Add".
   - Open Pip from the new icon. It runs full-screen, and after the
     first open it works without internet.

3. FIRST TIME, AS A GROWN-UP
   - Tap "Grown-ups" and set your PIN.
   - Settings: enter her name, tap "Test the voice".
   - Test lists: "Add this week's list" and paste her words.
     (A sample list is already loaded; delete it once hers is in.)

GOOD TO KNOW
   - Her progress is saved on that iPad only. Every so often use
     Grown-ups > Settings > Save a backup (save it to Files or iCloud Drive).
   - Deleting the Pip icon from the Home Screen deletes her progress too,
     unless you have a backup.
   - Sentences: type them after a colon, e.g.  said: Mom said hello.
     (Claude can write a batch for you in the "spelling app" project.)
   - Updates: if Claude makes changes, upload the new docs folder to the
     repository again. The iPad picks it up on its next launch or two.
